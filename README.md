# blog_dzen

Автоматическое ведение блога на Дзене (`dzen.ru`) о дизайне интерьера.
2-3 публикации в неделю, тексты в личном/душевном тоне.

## Что делает

1. По расписанию (ПН, СР, ПТ в 10:00 МСК) выбирает свежую тему из базы.
2. Через **Claude (ProxyAPI)** генерирует статью в выбранном личном тоне.
3. Через **DALL-E 3 (ProxyAPI)** рисует обложку.
4. Драфт улетает в Telegram владельцу — он принимает или отклоняет.
5. После принятия Playwright-скрипт публикует статью на dzen.ru с авторизацией через сохранённые куки.

## Структура

```
blog_dzen/
├── README.md
├── STATE.md
├── code/
│   ├── .env              # секреты (никогда не коммитятся)
│   ├── config.py         # загрузка .env
│   ├── llm_writer.py     # генерация статьи через Claude
│   ├── image_gen.py      # DALL-E 3 для обложки
│   ├── topic_planner.py  # выбор темы из базы
│   ├── db.py             # SQLite: история тем и постов
│   ├── notify.py         # уведомления и драфты в Telegram
│   ├── dzen_poster.py    # Playwright постит в Дзен
│   ├── main.py           # генерация → драфт в TG
│   ├── publish.py        # отдельный шаг: публикация одобренного драфта
│   ├── topics_seed.json  # стартовая база тем (~50 шт.)
│   └── requirements.txt
└── images/                # сгенерированные обложки
```

## Зависимости

- Python 3.12
- Playwright (chromium)
- ProxyAPI ключ (Claude + DALL-E через один ключ)
- Куки Дзена (экспортированные с авторизованного браузера)

## Расписание

systemd timer на сервере: ПН/СР/ПТ 10:00 МСК → `main.py` → драфт в TG.
После одобрения — `publish.py` запускается вручную или через колбэк бота.
